# Phone Repair Service Center

Система управления сервисным центром по ремонту мобильных телефонов на **PHP + MySQL**, с тремя ролями: администратор, клиент и техник. Интерфейс переведён на **русский язык**.

## Возможности

- Клиент: оформление заявки на ремонт, отслеживание статуса, история обращений
- Техник: просмотр назначенных заявок, обновление статуса ремонта
- Админ-панель: назначение заявок техникам, управление брендами техники и техниками, отчёты (по датам, по сотрудникам, по продажам)

## Технологии

- PHP, MySQL (mysqli)
- HTML, CSS, Bootstrap, jQuery

## Установка (XAMPP)

1. Скопируйте папку проекта в `C:\xampp\htdocs\`.
2. Запустите **Apache** и **MySQL** в XAMPP Control Panel.
3. Создайте базу данных `acrsdb` и импортируйте дамп `acrsdb.sql` через phpMyAdmin.
4. Проверьте параметры подключения в файлах `*/includes/dbconnection.php`.
5. Откройте в браузере: `http://localhost/<папка_проекта>/` (панели доступны через `/admin`, `/user`, `/technician`).
